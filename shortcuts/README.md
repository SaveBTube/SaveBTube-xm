# 📱 iOS 快捷指令 - 快速开始

## 🚀 3 分钟快速安装

### 步骤 1：访问安装页面

在 iPhone Safari 中打开：
```
http://your-server:8080/shortcuts/install
```

### 步骤 2：安装快捷指令

1. 点击 **📲 安装快捷指令** 按钮
2. 在弹出窗口点击 **添加快捷指令**
3. 完成！

### 步骤 3：配置服务器地址

1. 打开 **快捷指令** App
2. 找到 **Bosco 下载**
3. 点击编辑
4. 修改 `http://your-server:8080` 为您的实际地址
5. 完成！

---

## 📖 使用示例

### 从 Safari 下载

1. 打开 YouTube 视频
2. 点击 **分享** 按钮
3. 选择 **Bosco 下载**
4. 输入 API Key（首次）
5. ✅ 下载开始！

### 从任何 App 下载

1. 复制视频链接
2. 点击分享
3. 选择 Bosco 下载
4. 完成！

## ⚙️ 修改画质

编辑快捷指令 → 找到 `quality` 字段 → 修改为：
- `best` - 最佳画质（默认）
- `1080p` - 1080p
- `720p` - 720p
- `audio` - 仅音频
- `mp3` - MP3 格式
