- **入口与路由层**：`backend/main.py` 作为核心入口，定义 FastAPI 应用生命周期（`lifespan`），集中管理所有 RESTful API 路由（认证、下载、订阅、统计等）。
- **业务逻辑层**：`backend/admin/` 封装核心功能，其中 `auth.py` 处理 Bearer Token 与 API Key 的生成与校验；`db.py` 基于 SQLite 实现用户、任务、历史记录及系统设置的持久化存储；`telegram_bot.py` 与 `twitter_downloader.py` 分别负责 Telegram 消息轮询与 X/Twitter 专用资源提取。
- **配置与工具层**：`backend/config.py` 负责加载 `BoscoTsang.toml` 配置文件并动态管理代理环境变量，支持全局、自动或无代理模式。
- **依赖方向**：主应用依赖 `admin` 子模块提供的数据库操作与认证装饰器，所有模块通过共享的 SQLite 连接与内存状态（如下载进度字典）进行协同。
