- 采用基于角色的访问控制（RBAC），通过 `@require_auth` 和 `@require_admin` 装饰器统一拦截并验证 HTTP 请求中的 Token 或 API Key。
- 下载任务采用异步触发机制，API 接口仅负责任务创建与 ID 返回，实际下载逻辑通过 `threading.Thread` 在后台执行以避免阻塞主线程。
- 所有文件系统操作均通过 `safe_download_path` 等辅助函数进行路径清洗，确保文件读写严格限制在配置的 `DOWNLOAD_DIR` 目录内，防止路径遍历攻击。
- 数据库操作遵循“获取连接-执行事务-关闭连接”的模式，并在 `db.py` 中为每个表操作提供独立的 CRUD 函数，保持数据访问层的原子性。
