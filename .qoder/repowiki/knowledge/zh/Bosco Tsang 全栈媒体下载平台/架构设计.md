- **单体容器化部署**：采用多阶段 `Dockerfile` 将 Vue 前端构建产物嵌入 FastAPI 后端的静态目录，实现单容器交付，简化运维复杂度。
- **统一 API 网关**：后端作为唯一入口，既处理业务逻辑（下载调度、用户认证），又直接托管前端静态文件及 iOS 快捷指令安装页，消除跨域问题。
- **共享持久化层**：通过 `docker-compose.yml` 挂载统一的宿主机目录（downloads, cookies, data），确保下载文件、平台鉴权 Cookie 及 SQLite 数据库在容器重启或更新后不丢失。
- **配置驱动运行**：根目录 `BoscoTsang.toml` 与 `.env` 共同定义代理策略、日志级别等全局行为，后端启动时加载并动态应用于 yt-dlp 及 HTTP 客户端。
